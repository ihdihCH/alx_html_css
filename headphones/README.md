# 🎧 Headphones Landing Page — ALX Front-End Project

This project is a responsive landing page for a headphones brand, created based on the Figma design provided by ALX.

The objective is to build a pixel-perfect web page from the UI design and ensure correct responsiveness and interactions.

---

## 📁 Project Structure

```
headphones/
│── index.html
│── styles.css
└── README.md
```

---

## 🎨 Figma Design

You must open the Figma file and **Duplicate it into your Drafts** to access all elements.

If fonts are missing, download them:

- **Source Sans Pro**
- **Spin Cycle OT**

Some values in Figma may be decimals — rounding is allowed.

---

## 📱 Responsiveness Rules

The layout must switch to **mobile view** when:

```
screen width ≤ 480px
```

Mobile changes include:

- stacked layout
- centered elements
- reduced spacing
- flexible card widths

---

## ✨ Required Interactions

### Links hover/active:

```
color: #FF6565;
```

### Button hover/active:

```
opacity: 0.9;
```

---

## 📏 Layout Requirement

All content must stay inside a centered container:

```
max-width: 1000px;
margin: 0 auto;
```
